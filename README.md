# Learn OKEY / 学习 OKEY

A practical introduction to classic OKEY and 101 Okey. Read in your language, work through a hand and use the score sheet.

用自己的语言学习经典 OKEY 与 101 Okey，完成牌例练习并记录一场牌局。

## What you can do / 可以完成什么

Recognize the joker → build groups → practice a turn → record results.

辨认百搭 → 组成合法组合 → 练习回合 → 记录结果。
