# OKEY：从认牌到完成一局

[English](en.md) · [简体中文](zh.md) · [Türkçe](tr.md) · [Deutsch](de.md)

本课可直接用于四人手动练习。先练经典 OKEY，再练 101 Okey；自动桌如何装牌和选择模式，应按对应设备说明操作。本课给出基础流程和练习用计分安排，不代替某个俱乐部的完整赛事规程。

## 1. 把牌和桌面准备好

游戏牌共106张：四种颜色、1至13、各两张，共104张数字牌，另有两张假百搭。备用牌另放。四人坐好，约定逆时针轮流，选择发牌者；发牌者右手边的玩家先出牌。

手动教学可用简化发牌：将牌背面朝上混匀，随机翻出一张普通数字牌作为指示牌并留在桌面；先手取15张，其余各14张，剩余牌背面朝上作为摸牌区。若翻到假百搭，放回重选。先手先出一张，不再额外摸牌。这是便于练习的发牌方式；正式牌局可采用事先约定的骰子与牌墩程序。

## 2. 先认百搭，再整理手牌

指示牌称为 **gösterge**。同色下一数字的两张牌成为真百搭 **okey**，13的下一张是1。假百搭 **sahte okey** 只能当作这个数字、这个颜色的普通牌。

| 指示牌 | 真百搭 | 假百搭的普通牌身份 |
|---|---|---|
| 蓝8 | 蓝9 | 普通蓝9 |
| 黑13 | 黑1 | 普通黑1 |

把同色数字排在一起，再找相同数字的不同颜色。百搭先单独放在手牌中容易看见的位置，并在检查组合时明确它替代什么。

## 3. 认识合法组合

| 组合 | 合法示例 | 常见错误 |
|---|---|---|
| 同色顺子，至少3张 | 红3-4-5；蓝6-7-8-9 | 红3、蓝4、红5混色 |
| 同数异色组，3或4张 | 红7、蓝7、黑7 | 红7、红7、蓝7重复颜色 |
| 经典OKEY的七对 | 7组同色同数的对子 | 把红5和蓝5当作一对 |

经典 OKEY 常见规则允许同色12-13-1，但不允许13-1-2。下文所采用的101规则不允许12-13-1。一张实体牌只能归入一个组合。

## 4. 一回合：取一张，再出一张

除先手第一步外，轮到你时：从摸牌区取一张背面朝上的牌，或取上家刚刚打出的那一张；整理后向右侧弃牌位置打出一张。不能从任意玩家的旧弃牌中挑牌。经典 OKEY 的组合留在自己手中，到结束时再展示。

普通回合取牌后有15张、弃牌后有14张。准备结束时，留下的14张必须能完整分成合法组，或满足七对；再打出第15张，并展示排列给大家核对。

## 5. 完整牌例：还差哪一张？

本例指示牌为黑4，黑5是百搭；下列牌都按普通身份使用。

| 你现有的14张牌 | 张数 |
|---|---:|
| 红2-3-4-5 | 4 |
| 蓝6-7-8 | 3 |
| 黑10-11-12 | 3 |
| 红1、蓝1、黄1 | 3 |
| 单独的黑3 | 1 |

现在摸到蓝9，你有15张。把蓝9接到蓝色顺子，打出黑3，剩下`4+4+3+3=14`张，每一组均合法。不能既把某张蓝7放进顺子，又把同一张牌算入一个同数组。

## 6. 把这一局记下来

首次教学可明确约定：玩3局，结束成功者记+1，其他人记0，摸牌区用完且无法按约定继续时无人得分；每局轮换先手。这是教学积分，不是通用OKEY结算标准，也不含七对或百搭结束的奖励。

| 记录 | A | B | C | D |
|---|---:|---:|---:|---:|
| 初始 | 0 | 0 | 0 | 0 |
| 第1局，B完成 | 0 | +1 | 0 | 0 |
| 第2局，A完成 | +1 | 0 | 0 | 0 |
| 第3局，B完成 | 0 | +1 | 0 | 0 |
| 最终 | 1 | 2 | 0 | 0 |

转入正式牌局前，把初始分数、胜负方向、七对、亮指示牌、百搭结束、流局和处罚全部写进桌规表，不把这个练习计分当成正式规则。

## 7. 再练101 Okey

仍用106张游戏牌及同一百搭判断法，但先手22张、其余各21张。先手可以做合法开牌，再弃一张；之后按逆时针取牌、进行允许的亮牌或接牌、弃牌。每次结束也必须留一张用于最后弃牌，不能把手牌全部摆出而无牌可弃。

常规开牌：在同一回合从自己的手牌摆出总值至少101的合法顺子或同数组。数字按所代表的数值相加，百搭按替代的数字计值；不能把接到别人已亮组合上的牌算进自己的开牌门槛。

| 本次开牌 | 分值 |
|---|---:|
| 红10-11-12-13 | 46 |
| 蓝7-8-9 | 24 |
| 三种不同颜色的11 | 33 |
| 合计 | **103，可以常规开牌** |

开牌后，可继续摆出合法组合，或按所选规则给桌面组合接牌。上家弃牌不能拿来暂存：本课引用的101规则要求立即使用；尚未开牌时，它必须参与本次达标的开牌。桌上已用的百搭不按Rummikub方式随意取回或换位。

另有对子开牌路线：所引用基线要求同回合至少5对同色同数的牌；开对子之后不再新开顺子或同数组，但可给别人已有的顺子或同数组接牌。第一次练习先只选常规开牌路线。特殊结束、对子计分、未开牌处罚及加倍方式必须另行约定；“101”不是牌数。

## 8. 三个自测

1. 指示牌红13时，假百搭能随意替代黑6吗？不能，它代表普通红1。
2. 101组合的分值合计98，可以先摆下后面再补到101吗？常规开牌不可以，首次开牌须在同回合达标。
3. 最后两张为蓝7、蓝8，摸到蓝9，能把三张全部摆出结束101吗？不可以，仍须留最后一张弃牌。
